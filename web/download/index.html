Requisitos mínimos

  • Sistema

    Windows 10 (64 bits) ou superior. Windows 11 recomendado.

  • Processador

    Intel/AMD dual-core 1.6 GHz ou superior (recomendado quad-core).

  • Memória

    4 GB RAM mínimo. 8 GB ou mais recomendado.

  • Disco

    600 MB livres para instalação + espaço para seus documentos.

  • Internet

    Recomendado para chat com IA, atualizações automáticas e licenças.

  • Permissões

    Conta de administrador para a primeira instalação.

Como instalar

  1. 1

    Baixe o instalador

    Clique no botão BAIXAR PARA WINDOWS acima. O arquivo tem cerca de {{FILE_SIZE}}.

  2. 2

    Abra o arquivo baixado

    Localize o instalador na pasta Downloads e dê duplo-clique. O Windows pode perguntar "Deseja permitir que este app faça alterações?" — responda Sim.

    SmartScreen: Na primeira execução o Windows pode mostrar um aviso de segurança (instalador não-assinado digitalmente). Clique em Mais informações → Executar mesmo assim. Esse aviso some em versões futuras quando o certificado for aplicado.

  3. 3

    Siga o instalador

    Escolha a pasta de instalação (ou aceite o padrão) e clique em Instalar. O assistente cuida de tudo.

  4. 4

    Abra o Pi Agente Kairós

    Ao terminar, o app abre automaticamente. Faça login com sua conta ou ative sua licença — a validação é feita pela nossa API.
